# Kryostat

Приложение для контроля и оптимизации Windows 10/11 (x64).

![Kryostat](assets/logo256.png)

## Возможности

| # | Раздел | Что делает |
|---|--------|------------|
| 1 | **Процессы и службы** | Диспетчер задач, который показывает и запущенные процессы, и **все службы Windows, включая остановленные**. Фильтры: только процессы / только службы / запущенные / не запущенные / критичные / сторонние. |
| 2 | **Красная подсветка** | Критичные для работы Windows процессы и службы выделены красным жирным, их завершение программно заблокировано. |
| 3 | **Автозапуск** | Сканирует реестр (HKCU/HKLM Run, RunOnce, WOW6432Node), папки автозагрузки и задачи планировщика. **Дубликаты** (одна программа прописана несколько раз) подсвечиваются янтарным с пометкой ×N. |
| 4 | **Отключение автозапуска** | Галочкой или кнопкой; изменения **обратимы** (запись переносится в `HKxx\Software\Kryostat\DisabledStartup`) и сохраняются в конфиг. Кнопка «Отключить дубликаты» оставляет по одной записи на программу. |
| 5 | **Лимиты ресурсов** | На программу: максимум ОЗУ и максимум CPU (Windows **Job Objects**, жёсткий cap), число доступных ядер, приоритет CPU, низкий приоритет диска, ограничение скорости сети (**политика QoS**). Правило привязано к имени `.exe` и автоматически применяется к новым запускам. |
| 6 | **Обновления Windows** | Каждый день автоматически сдвигает окно паузы обновлений на +N дней, чтобы Windows не перезагружала ПК. |
| 7 | **Автозапуск Kryostat** | Старт вместе с Windows (задача планировщика `KryostatBoot` с правами админа; если прав нет — запись в `HKCU\...\Run`) и немедленное завершение всех программ, которые вы отключили в автозапуске. |
| 8 | **Оптимизация Windows** | 16 твиков, которые выполняют команды от имени администратора: `sc config DiagTrack start= disabled`, `sc stop DiagTrack`, `sc config dmwappushservice start= disabled` и т.д., плюс правки реестра. У каждого есть **команда отката**. |
| 9 | **Монитор ресурсов** | CPU по ядрам, ОЗУ, диск (чтение/запись), сеть, накопители, топ-потребители по CPU / памяти / диску / сетевым соединениям. |
| 10 | **Компьютер** | Сведения о системе и железе, аптайм, журнал включений/выключений, статистика запуска программ (своя и UserAssist Windows), питание: перезагрузка, выключение, BIOS/UEFI, безопасный режим, отложенное выключение. |
| 11 | **Антивирус** | Microsoft Defender: состояние, защита в реальном времени, настройки, нагрузка на CPU, исключения, проверки (быстрая / полная / папка / автономная), сигнатуры, найденные угрозы. |
| 12 | **Реестр** | Редактор реестра с ленивым деревом, всеми основными типами значений, поиском в фоне, избранным, экспортом/импортом `.reg` и резервной копией раздела перед каждым изменением. |
| 13 | **Терминал** | Вкладки PowerShell / pwsh / cmd / Git Bash с правами «как есть», «администратор» или «без прав», плюс журнал команд самого Kryostat. |

Дополнительно: иконка в трее, работа в фоне, журнал действий, 5 базовых тем × 12 акцентных цветов (или свой HEX), автоматический язык интерфейса.

## Интерфейс, темы и язык

- **Ctrl+K** — палитра команд (поиск по страницам и действиям), **Ctrl+1…9** — быстрый переход, **Ctrl+B** — компактная боковая панель.
- Настройки → «Оформление»: база (Midnight, Graphite, AMOLED, Ocean, Light) и акцентный цвет (12 вариантов или свой HEX).
- Язык интерфейса определяется по языку Windows. Если перевода нет — используется английский. Выбрать вручную: Настройки → «Язык интерфейса».

### Как добавить перевод

Создайте `assets/locales/<код>.json` (например `de.json`) по образцу `en.json`:

```json
{"meta": {"name": "German", "native": "Deutsch", "code": "de"},
 "strings": {"Настройки": "Einstellungen"}}
```

Чтобы получить список непереведённых строк, запустите приложение с переменной окружения `KRYOSTAT_I18N_MISSING=missing.txt`.

## Требования

- Windows 10 / 11, 64-бит
- Python 3.10–3.13 (только для сборки) — https://www.python.org/downloads/
- Inno Setup 6 (только для установщика) — https://jrsoftware.org/isdl.php

## Сборка

Клонируйте репозиторий (или скачайте ZIP), откройте папку и запустите:

```bat
build.bat
```

Скрипт сам создаст окружение, поставит зависимости, соберёт `.exe` и установщик.

Результат:
- `dist\Kryostat\Kryostat.exe` — портативная сборка
- `dist\KryostatSetup.exe` — установщик

### Если хотите вручную

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install pyinstaller

:: 1) приложение
pyinstaller --noconfirm --clean Kryostat.spec

:: 2) установщик
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

### Один файл вместо папки (медленнее стартует)

```bat
pyinstaller --noconfirm --clean --onefile --windowed --uac-admin ^
  --name Kryostat --icon assets\kryostat.ico ^
  --version-file version_info.txt ^
  --add-data "assets;assets" main.py
```

### Запуск без сборки (отладка)

```bat
run_dev.bat
```

## Ключи запуска

| Ключ | Назначение |
|------|------------|
| `--boot` | Режим автозапуска: глушит отключённые программы, применяет твики и лимиты, продлевает паузу обновлений |
| `--minimized` | Свернуть в трей при старте |
| `--no-elevate` | Не запрашивать UAC повторно |
| `--restarted` | Перезапуск «от администратора»: ждать закрытия старого экземпляра |
| `--register-task` / `--unregister` | Служебные режимы для установщика: создать / удалить автозапуск и выйти |

## Где хранятся данные

`C:\ProgramData\Kryostat\`: `config.json`, журнал `kryostat.log`, статистика программ `usage.json`, резервные копии реестра `registry-backups\`.

## Важно

- Приложение запрашивает права администратора — без них недоступны управление службами, политики обновлений и лимиты для системных процессов.
- Пауза обновлений Windows ограничена самой ОС **35 днями**. По достижении лимита нужно один раз установить накопившиеся обновления, затем отсчёт начнётся заново. Полностью отключать обновления безопасности не рекомендуется.
- Лимит скорости сети через QoS работает для приложений, у которых трафик идёт от самого процесса; трафик через системные службы (например BITS) политикой по имени .exe не ловится.
- Все твики обратимы кнопкой «Откатить отмеченные». Перед массовым применением желательно создать точку восстановления системы.
